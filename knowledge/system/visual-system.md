# State Visual System

Канонический общесистемный контракт, материализованный в Patch v0.1.1. Будущие `states/{state_id}/visual.md` подчиняются этим правилам и [State System](state-system.md).

State identity в перспективе включает:

```text
philosophy + icon + motion + sound + tea/product relations + content language
```

Общие утверждённые брендовые параметры:

```text
primary: #1E3932
accent: #EABC6F
font: Cera Pro
```

Это Knowledge-level параметры из утверждённого patch, не изменение CSS tokens приложения. Для конкретного UI сохраняется приоритет Figma по [корневым инструкциям](../../AGENTS.md); UI и assets в рамках patch не меняются.

State icons должны:

- различаться прежде всего формой и семантикой, а не только цветом;
- работать в monochrome и в малом размере;
- работать как video watermark;
- допускать engraving/packaging use;
- иметь понятную icon semantics;
- в будущем иметь clear-space/min-size rules и motion signature.

Конкретные минимальные размеры, clear-space и animation параметры здесь не изобретаются. Сами 11 иконок, графические assets и runtime visual integration сейчас не создаются.
